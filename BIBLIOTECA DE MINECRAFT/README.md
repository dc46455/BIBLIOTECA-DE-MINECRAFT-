# ⛏️ Biblioteca Oficial de Minecraft - Tienda & Lector Digital

Una tienda y biblioteca virtual interactiva desarrollada en **HTML5, CSS3 y JavaScript**, diseñada para ejecutarse de inmediato en **Visual Studio Code**, **Visual Studio** o directamente en cualquier navegador web.

---

## 📚 Colección Oficial de Libros

La interfaz está optimizada de forma limpia y directa con los **4 libros oficiales** y sus portadas originales:

1. **Minecraft: Manual de Supervivencia** (*Portada Verde con Pico Dorado*) — `$14.99 USD`
2. **Minecraft: Manual de Redstone** (*Portada Roja con Polvo de Redstone*) — `$14.99 USD`
3. **Minecraft: Guía de Combate** (*Portada Púrpura con Espada Dorada*) — `$15.99 USD`
4. **Minecraft: Manual del Explorador** (*Portada Azul con Hacha/Pala Dorada*) — `$14.99 USD`

---

## 🛒 Funciones de Compra y Lectura

- **Catálogo Limpio**: Muestra directamente los libros oficiales sin barras de búsqueda innecesarias ni tarjetas de estadísticas redundantes.
- **Carrito de Compras en la Barra Superior (`🛒`)**:
  - Badge dinámico con el número de libros agregados.
  - Modal de carrito con miniaturas, controles de cantidad (`＋` / `－`) y cálculo de totales.
  - Simulación de compra con recibo y confirmación.
- **Lector Interactivo de Muestras (`📖`)**:
  - Lee los capítulos completos de cada libro.
  - Modos de lectura (*Sepia*, *Blanco*, *Noche*), tamaño de letra (`A-` / `A+`) y barra de progreso.

## 🚀 Cómo ejecutarlo en Visual Studio / VS Code

### Opción 1: Visual Studio Code con Live Server
1. Abre **Visual Studio Code**.
2. Abre la carpeta `BIBLIOTECA DE MINECRAFT`.
3. Haz clic derecho sobre `index.html` y selecciona **"Open with Live Server"**.

### Opción 2: Directo en tu navegador
1. Haz doble clic en `index.html` en el Explorador de Archivos de Windows.
